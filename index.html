PRODUCTOS

Cuatro productos para la gestión pedagógica

Cada producto resuelve un proceso del trabajo técnico pedagógico y se usa desde una misma plataforma.

Planificación

Plataforma para realizar el proceso de planificación anual, de unidad y clase a clase.

Evaluación

Plataforma para realizar el proceso de evaluación, revisión y análisis de datos. Incluye remediales.

Acompañamiento al Aula

Para equipos directivos: pautas de acompañamiento al aula y análisis institucionales.

Integración

Dinamiza los procesos evaluativos de los programas de integración.
